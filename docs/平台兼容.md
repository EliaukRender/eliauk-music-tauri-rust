# Windows / macOS 兼容

目标平台为 Windows 10+（x64）和 macOS 10.15+（arm64、x64 分别打包）。Linux 可以编译，但不在测试范围内。

## 前端判断平台

使用 `src/utils/platform.ts` 导出的 `currentPlatform` / `isMacOS` / `isWindows` / `isDesktop`。值在模块加载时计算一次（基于 `@tauri-apps/plugin-os`），浏览器调试时为 `web`。

平台差异优先通过 **Tauri 平台配置文件** 或 **Rust `#[cfg(target_os)]`** 处理，前端分支只用于界面上的差异（比如是否渲染窗口按钮、是否为红绿灯留出空间）。

## macOS 注意事项

- **红绿灯位置**：`trafficLightPosition` 为 `{ x: 18, y: 22 }`，与 56px 高的标题栏垂直居中对齐。修改标题栏高度时要同步调整。
- **签名与公证**：
  - 本地和 CI 默认使用 ad-hoc 签名，可以在本机运行。分发给他人时，对方首次打开需要右键「打开」。
  - 正式分发需要配置 Developer ID 证书与公证，在 CI 中注入 `APPLE_CERTIFICATE`、`APPLE_ID` 等环境变量（参考 tauri-action 文档）。
  - 开启 hardened runtime 后，内嵌 sidecar（Node/V8）需要 `Entitlements.plist` 中的 `allow-jit` 和 `allow-unsigned-executable-memory`，否则会闪退。
- **透明窗口**：需要 `macOSPrivateApi: true`，代价是无法上架 Mac App Store。当前主窗口不透明；mini 播放器是否透明见 [功能方案/07-迷你播放器.md](./功能方案/07-迷你播放器.md)。
- **Universal 包**：pkg 产物不支持 lipo 合并，arm64 和 x64 分开发布。

## Windows 注意事项

- **WebView2**：Win10 需要 WebView2 运行时。安装包默认使用 `downloadBootstrapper`，离线环境可以改成 `embedBootstrapper` 或 `offlineInstaller`（安装包会变大）。
- **代码签名**：未签名的安装包会触发 SmartScreen 提示；正式分发需配置证书（`bundle.windows.certificateThumbprint` 或 Azure Trusted Signing）。
- **拖放**：窗口设置了 `dragDropEnabled: false`，否则 WebView2 会拦截 HTML5 拖放，歌单拖拽排序会失效。
- **本机交叉编译**：在 macOS 上可以交叉打出 Windows 版 sidecar。但 Rust 部分编译 Windows 资源文件需要 `llvm-rc`，所以 Windows 的编译验证依赖 CI（`.github/workflows/ci.yml` 中的 `windows-latest` 矩阵）。

## 验证清单（每次发版前）

- [ ] 两个平台下窗口拖拽、双击标题栏、最小化/最大化/关闭表现符合上表
- [ ] 关闭行为为「最小化」时：macOS 可从 Dock / 托盘恢复，Windows 可从托盘恢复
- [ ] 关闭行为为「退出」时：两个平台进程完全退出（包括 sidecar）
- [ ] 托盘菜单「显示主界面 / 退出」可用，macOS 深浅色菜单栏下图标清晰
- [ ] 第二次启动应用只会唤起已有窗口
- [ ] 重启后窗口位置和尺寸恢复
- [ ] 设置页「测试连接」成功，接入形态显示正确
- [ ] 强杀主进程后 2s 内 sidecar 自行退出（macOS：活动监视器；Windows：任务管理器）
