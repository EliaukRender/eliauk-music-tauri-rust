# 开发规范

## 环境

| 工具 | 版本                                        |
| ---- | ------------------------------------------- |
| Node | 22+（见 `.nvmrc`）                          |
| pnpm | 11（见 `package.json` 的 `packageManager`） |
| Rust | stable（见 `rust-toolchain.toml`）          |

npm 源在项目的 `.npmrc` 中固定为 `https://registry.npmmirror.com`，不受全局 registry 配置影响。

## 命名

| 对象             | 规则                          | 示例                             |
| ---------------- | ----------------------------- | -------------------------------- |
| 目录             | kebab-case                    | `views/music-hall/`              |
| Vue 组件文件     | PascalCase                    | `PlayerBar.vue`                  |
| 页面组件         | `XxxView.vue`                 | `DiscoverView.vue`               |
| 组合式函数       | camelCase，`use` 前缀         | `useThemeMode.ts`                |
| Pinia store      | `useXxxStore`，文件名为领域名 | `stores/player.ts`               |
| Rust 模块 / 函数 | snake_case                    | `api_server`、`show_main_window` |
| Tauri 命令       | snake_case 动宾结构           | `get_api_endpoint`               |
| Tauri 事件       | `领域://动作`                 | `api://endpoint-changed`         |
| 文档             | 中文文件名                    | `docs/架构设计.md`               |

## TypeScript / Vue

- 使用 `<script setup lang="ts">` 和 Composition API。
- 类型声明用 `type`，不用 `interface`（`.d.ts` 模块扩充除外）；不使用 `enum`，改用 `as const` 对象加派生类型。以上规则由 ESLint 强制。
- 类型导入使用 inline 写法：`import { type Foo, bar } from '...'`。
- 导入顺序由 `simple-import-sort` 自动整理。
- 模板中的组件用 PascalCase；naive-ui 组件（`n-*`）和图标（`i-ri-*`）由 unplugin-vue-components 自动注册，保持 kebab-case，不需要手动 import。
- 在 script 中使用图标组件（比如菜单配置）时显式导入：`import IconX from '~icons/ri/x-line'`。
- 业务代码不直接使用 axios，一律通过 `api/http.ts` 暴露的 `get` / `post`。
- 业务代码不直接 import `@tauri-apps/*`，经由 `services/tauri/` 封装（`utils/platform.ts` 例外）。

## 样式

- 布局和间距优先使用 Tailwind 工具类；颜色使用语义 token（`bg-surface`、`text-muted`、`border-line`、`text-primary`），不写死色值，这样深色模式会自动适配。
- 组件内需要复用一组工具类时，在 `<style scoped>` 中 `@reference '@/assets/styles/main.css'` 后使用 `@apply`。
- 覆盖 naive-ui 组件样式优先使用 `themeOverrides`（`src/theme/naive.ts`），其次才是工具类。

## Rust

- `cargo fmt` 与 `cargo clippy -D warnings` 必须通过，两种 feature 组合都要检查（`pnpm lint:rust` 使用 `--all-features`，CI 会分别检查）。
- 仅内嵌形态需要的代码必须放在 `#[cfg(feature = "embedded-api")]` 之后，确保远程形态的产物里不包含它们。
- 平台差异使用 `#[cfg(target_os = "...")]`，不要在运行时判断。
- 命令返回 `Result<T, String>`，错误信息使用中文，前端可直接展示。
- 前端可调用的能力必须在 `capabilities/default.json` 中显式声明，按最小权限原则开放。

## 测试

| 层   | 工具                                    | 位置                              | 命令             |
| ---- | --------------------------------------- | --------------------------------- | ---------------- |
| 前端 | Vitest + happy-dom（+ @vue/test-utils） | 与源文件同目录的 `*.test.ts`      | `pnpm test`      |
| Rust | `cargo test`                            | 模块内的 `#[cfg(test)] mod tests` | `pnpm test:rust` |

- **必须覆盖**：纯逻辑模块，比如 `utils/`、`services/` 中的解析和状态机、store 的 action（播放模式切换、队列增删、歌词解析、切歌竞态等），以及 Rust 端的纯函数和序列化约定。
- **不强制覆盖**：页面布局和纯展示组件、依赖真实 WebView 或窗口的行为。后者按 [平台兼容.md](./平台兼容.md) 的验证清单手工回归。
- Tauri API 统一用 `vi.mock('@tauri-apps/api/...')` 模拟；HTTP 通过替换 `http.defaults.adapter` 模拟，不发出真实请求。可以参考 `src/api/http.test.ts` 和 `src/services/tauri/api-endpoint.test.ts`。
- 用例名使用中文描述行为，比如 `it('失败后下次调用会重试')`。
- 暂不引入 E2E：tauri-driver 不支持 macOS（WKWebView 没有 WebDriver），等 Windows 端需要回归时再评估。
- CI 会执行 `pnpm test`，并在两个平台、两种 feature 组合下执行 `cargo test`。

## 注释

只记录约束、陷阱和非显而易见的决策依据，不复述代码行为。

## Git

- 分支：`main` 为主干，功能分支 `feat/<领域>-<简述>`，修复分支 `fix/<简述>`。
- 提交信息：`type(scope): 中文描述`，由 commitlint 校验。
  - type 可选：`feat` `fix` `perf` `refactor` `style` `docs` `test` `build` `ci` `chore` `revert`
  - scope 建议使用领域名：`player`、`playlist`、`lyric`、`api`、`sidecar`、`window`、`tray`、`ui`、`deps`
  - 示例：`feat(player): 支持单曲循环`
- 提交前 husky 执行 lint-staged（ESLint、Prettier、rustfmt）。
- husky 需要 `.git` 目录存在：初始化仓库后执行一次 `pnpm install`（会运行 `prepare`）以安装钩子。

## 常用命令

```bash
pnpm dev                 # 内嵌形态开发（自动构建 sidecar）
pnpm tauri:dev:remote    # 远程形态开发（需配置 VITE_API_BASE_URL）
pnpm dev:web             # 仅前端，浏览器调试
pnpm sidecar:serve       # 以 node 直接启动 API（端口 30488），配合 dev:web 使用

pnpm build               # 内嵌形态打包
pnpm tauri:build:remote  # 远程形态打包

pnpm lint / lint:fix     # ESLint
pnpm format              # Prettier
pnpm typecheck           # vue-tsc
pnpm test / test:watch   # Vitest
pnpm test:rust           # cargo test
pnpm lint:rust           # rustfmt + clippy
pnpm icons               # 由 design/icons/*.svg 重新生成全部图标
```
