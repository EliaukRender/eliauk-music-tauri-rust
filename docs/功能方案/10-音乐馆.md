# 10 音乐馆（精选 / 排行 / 歌手）

## 1. 背景

### 旧实现位置

| 文件                                                                                                            | 内容                                                                                                       |
| --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `src/renderer/views/MusicHome/MusicHome.tsx`                                                                    | 音乐馆入口：标题加分类 Tab（精选、排行、歌手），滚动超过 45px 后分类栏吸顶；首次进入跳转到第一个分类       |
| `src/renderer/constant/index.ts#MusicHomeSortList`                                                              | 分类与子路由（`cherryPickCmp`、`rank`、`singer`）                                                          |
| `src/renderer/views/MusicHome/views/CherryPick.tsx`                                                             | 精选页：`/music/queryMusicHomeSheet` 返回按 `collectionId` 分组的歌单；第 1 组用于轮播，其余每组是一行推荐 |
| `src/renderer/views/MusicHome/components/cherryPickCmp/{CarouselRecommend,NormalRecommend,NormalSheetCard}.tsx` | 轮播（gsap 动画）、分组标题加横向卡片、歌单卡片                                                            |

### 已知缺陷

- 数据来自自建后端的人工分组，迁移后需要换成网易云的数据源。
- 排行和歌手没有实现。
- 点击歌单卡片没有跳转到详情页（旧项目的歌单详情只支持自建歌单）。

## 2. 目标与范围

本期实现：

- **精选**：顶部 Banner 轮播；下方分区依次为「推荐歌单」（未登录使用 `/personalized`，登录后使用 `/recommend/resource` 每日推荐）、「精品歌单」「新歌速递」
- **排行**：官方榜卡片（前 4 个榜单展示前 3 首歌曲）加全球榜网格；点击进入榜单详情（复用 04 的 `PlaylistView`，榜单本身就是歌单）
- **歌手**：按类型（全部/男/女/乐队）、地区（全部/华语/欧美/日本/韩国/其他）、首字母筛选；无限滚动；点击进入歌手页（热门 50 首 + 专辑列表，基础版）
- 分类 Tab 吸顶，切换时保留各页面的滚动位置（`KeepAlive`）
- 歌单卡片悬停时显示「播放」按钮，可以直接播放整个歌单

本期不做：

- 歌单分类广场（`/playlist/catlist`）、MV、电台、专辑详情页（后续补充）
- 旧项目的「视频」「世界」入口

## 3. 方案设计

### 3.1 路由

```
/hall                → 重定向到 /hall/featured
/hall/featured       → views/hall/FeaturedView.vue
/hall/rank           → views/hall/RankView.vue
/hall/artists        → views/hall/ArtistsView.vue
/artist/:id          → views/artist/ArtistView.vue
/playlist/:id        → 复用 04
```

`views/hall/HallLayout.vue` 包含标题、吸顶 Tab（使用 `NTabs`，配合 `position: sticky`，不再需要 JS 监听滚动）以及 `<RouterView v-slot>` + `<KeepAlive>`。

### 3.2 组件

| 组件                                                           | 说明                                                                                                                   |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `src/components/cover/PlaylistCard.vue`                        | 封面（`?param=300y300`）、播放量角标、标题；悬停时显示播放按钮，点击后先获取歌单全部歌曲再调用 `player.playSongs`      |
| `src/components/cover/CardGrid.vue`                            | 响应式网格：CSS Grid 的 `repeat(auto-fill, minmax(160px, 1fr))`，替代旧项目用 JS 计算 padding 的 `useContainerPadding` |
| `src/views/hall/components/BannerCarousel.vue`                 | naive-ui `NCarousel`（自动播放、dots）；`targetType` 为 1（单曲）、10（专辑）、1000（歌单）时分别跳转或播放            |
| `src/views/hall/components/RankCard.vue`                       | 榜单卡片                                                                                                               |
| `src/views/hall/components/ArtistFilter.vue`、`ArtistCard.vue` | 歌手筛选与卡片                                                                                                         |

### 3.3 数据层

`src/api/modules/hall.ts`：

| 接口                            | 关键参数                                                                      | 用途                                   |
| ------------------------------- | ----------------------------------------------------------------------------- | -------------------------------------- |
| `GET /banner`                   | `type=0`（PC）                                                                | 轮播                                   |
| `GET /personalized`             | `limit=12`                                                                    | 推荐歌单（未登录）                     |
| `GET /recommend/resource`       | `cookie`                                                                      | 每日推荐歌单（登录后）                 |
| `GET /top/playlist/highquality` | `limit=12`                                                                    | 精品歌单                               |
| `GET /personalized/newsong`     | `limit=10`                                                                    | 新歌速递                               |
| `GET /toplist/detail`           | —                                                                             | 榜单列表，前几个榜单自带 `tracks` 预览 |
| `GET /artist/list`              | `type`（-1/1/2/3）、`area`（-1/7/96/8/16/0）、`initial`、`limit=30`、`offset` | 歌手列表                               |
| `GET /artist/top/song`          | `id`                                                                          | 歌手热门 50 首                         |
| `GET /artist/album`             | `id`、`limit`、`offset`                                                       | 歌手专辑                               |
| `GET /artist/detail`            | `id`                                                                          | 歌手信息                               |

数据获取方式：不建 store，页面级 composable 即可：`src/composables/useFeatured.ts`、`useToplist.ts`、`useArtistList.ts`。使用 `@vueuse/core` 的 `useAsyncState`。其中 `useArtistList` 的无限滚动通过 `useInfiniteScroll` 实现。

**缓存**：精选页数据在内存中缓存 10 分钟（composable 模块作用域中的 `Map`），与 `KeepAlive` 配合，切换 Tab 不会重复请求。

### 3.4 Tauri / Rust 侧

- 无。
- CSP 的 `img-src` 需要包含 `https://*.music.126.net http://*.music.126.net`（02 中已统一配置）。封面 URL 同样升级为 https。

## 4. Windows / macOS 差异

- 横向滚动行（如「新歌速递」）：mac 触控板原生支持横向滚动；win 鼠标只有纵向滚轮，需要在容器上监听 `wheel` 事件，把 `deltaY` 转成 `scrollLeft`（当 `deltaX === 0` 时才转换）。
- 吸顶 Tab 的 `top` 要等于 `--titlebar-height`，使 mac 红绿灯区域和 win 自绘标题栏都不被遮挡。
- 图片懒加载使用原生 `loading="lazy"`，WebView2 和 WKWebView 都支持。

## 6. 验收标准

- 未登录和登录两种状态下，精选页都有内容；登录后「推荐歌单」变成每日推荐。
- 在 Tab 之间切换时，滚动位置保持，且不重复请求。
- 排行页点击任意榜单能进入详情，并可以「播放全部」。
- 歌手页组合筛选后，无限滚动加载正常，没有重复数据。
- 在窗口宽度 1100 到 2560 之间，网格自适应，没有横向溢出。
- win 上用鼠标滚轮可以横向滚动「新歌速递」。

- Banner 中的广告类型（`targetType` 为 3000 的外链）是否展示：建议过滤掉。
