# 11 喜欢歌曲

## 1. 背景

### 旧实现位置

- `src/renderer/views/PlayerControlBar/components/LikeSong.tsx`：控制栏上的红心图片，`clickLikeSong` **只是阻止冒泡，没有任何业务逻辑**。
- `src/renderer/views/MiniPlayer/MiniPlayer.tsx`：mini 窗口的红心，调用 `miniPlayerEmitter.likeSong(id)`，主进程**没有对应的处理**。
- 路由 `like`（我的歌单）指向的是 `SheetCommon`，与「喜欢」无关，只是命名重叠。

结论：旧项目中「喜欢歌曲」**只有 UI，没有实现**，属于补齐功能。

## 2. 目标与范围

本期实现：

- 控制栏、mini 窗口、全屏歌词页展示当前歌曲的喜欢状态，点击可以切换
- 歌曲列表每一行展示红心状态，点击可以切换
- 右键菜单提供「喜欢 / 取消喜欢」（09）
- 喜欢或取消后，「我喜欢的音乐」歌单（04 中 `specialType === 5` 的歌单）数据同步刷新
- 未登录时点击红心，弹出登录框（01）
- 提供切换喜欢状态的快捷键 `Mod+L`（08）

本期不做：

- 「不喜欢」（FM 垃圾桶）
- 本地收藏（离线喜欢）

## 3. 方案设计

### 3.1 Store：`stores/like.ts`

```ts
state: {
  ids: Set<number>        // 喜欢的歌曲 id 集合，持久化时序列化为数组
  loadedFor: number | null  // 数据对应的 userId；与当前用户不一致时视为失效
  pending: Set<number>    // 请求中的 id，防止重复点击
}
getters: isLiked(id) => ids.has(id)
actions: {
  fetch()                 // GET /likelist?uid=，在登录后或 userId 变化时调用
  toggle(id)              // 乐观更新 → GET /like?id=&like=true|false → 失败时回滚并提示
                          // 成功后调用 playlistStore.invalidate(likedPlaylist.id)（04）
  clear()                 // 登出时调用
}
persist: { pick: ['ids', 'loadedFor'], serializer 负责 Set 与数组互转 }
```

Set 在 Pinia 中的响应式：Vue 3 的 `reactive` 支持 `Set` 的 `has`、`add`、`delete` 追踪，可以直接使用。

### 3.2 组件

- `src/components/player/LikeButton.vue`：props 为 `songId`、`size`。
  - 图标：`i-ri-heart-3-line` / `i-ri-heart-3-fill`（Iconify ri 集）；
  - 点击时有缩放动画；
  - pending 期间禁用；
  - 未登录时打开 `LoginModal`（01）。
- 复用位置：`PlayerBar`（02）、`SongList` 行（02）、`LyricView`（05）、mini 窗口（07）。

### 3.3 mini 窗口

- mini 窗口不直接调用 API，而是发送 `player://command { type: 'toggle-like', id }` 给主窗口（07 的统一指令通道）。
- 主窗口执行后，通过 `player://patch { liked }` 把结果回推给 mini 窗口。

### 3.4 接口

| 接口            | 关键参数                           | 说明                                           |
| --------------- | ---------------------------------- | ---------------------------------------------- |
| `GET /likelist` | `uid`、`cookie`                    | 返回 `ids: number[]`                           |
| `GET /like`     | `id`、`like=true\|false`、`cookie` | 喜欢或取消；必须带 `timestamp`，否则会命中缓存 |

### 3.5 Tauri / Rust 侧

无。

## 6. 验收标准

- 登录后，所有列表中的红心状态与网易云客户端一致。
- 点击红心后立即变色；断网时回滚并提示。
- 在 mini 窗口中点击红心，主窗口控制栏同步变化，反之亦然。
- 喜欢一首歌之后进入「我喜欢的音乐」，能在首位看到这首歌。
- 未登录时点击红心会弹出登录框。

## 7. 风险与待决策项

- `/like` 接口在高频调用时会触发风控（返回 `-460`）。在 `toggle` 中对同一个 id 做 500ms 节流。
- 跨账号切换时，持久化的 `ids` 必须与 `loadedFor` 一起校验，防止显示上一个账号的喜欢状态。
