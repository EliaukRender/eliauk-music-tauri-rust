# 图标设计

旧项目使用的卡通形象来源不明，存在版权风险，所以新项目重新设计了原创图标。

## 设计理念

- **字形**：由圆角「频谱条」拼成的字母 **E**，取自 Eliauk 的首字母，同时呼应频谱图这个特色功能。
- **声波点**：E 的中间一笔后跟两个逐渐变小变淡的圆点，表示声音向外扩散、渐隐。
- **配色**：品牌色从珊瑚粉 `#FF7A8A` 过渡到洋红 `#E0529C`，再到紫罗兰 `#6D4AFF`，沿对角线渐变；左上角叠加柔光高光。主色 `#E0529C` 也是应用的 `primary`（见 `src/theme/tokens.ts`）。

## 源文件与产物

| 源文件（`design/icons/`） | 用途                                                          | 产物                                                   |
| ------------------------- | ------------------------------------------------------------- | ------------------------------------------------------ |
| `app-icon.svg`            | 满版圆角方形，用于 Windows / Linux / 应用内 Logo              | `src-tauri/icons/*.png`、`icon.ico`、`public/logo.svg` |
| `app-icon-macos.svg`      | 按 macOS 图标网格留白：1024 画布中放置 824 圆角方形，带投影   | `src-tauri/icons/icon.icns`                            |
| `tray-template.svg`       | macOS 菜单栏：纯黑字形、透明背景，系统自动反色                | `icons/tray/tray-template.png`（22px）、`@2x`（44px）  |
| `tray.svg`                | Windows 托盘：彩色底、放大字形、去掉投影，保证 16/32px 下清晰 | `icons/tray/tray.png`（32px）                          |

修改 SVG 后执行 `pnpm icons` 重新生成全部产物（底层调用 `tauri icon`，它支持 SVG 输入，不需要额外安装图像工具）。

## 规格

- 画布 1024×1024，所有元素使用矢量路径，不嵌入位图。
- 满版圆角半径 228；macOS 版圆角方形 824×824、圆角半径 185，位于 (100,100)。
- 字形笔画宽 116，端点为全圆角；中间一笔短于上下两笔，给声波点留出空间。
- 字形投影：`dy=14`、`blur=18`，颜色 `#3A1470`，不透明度 35%。托盘图标不加投影。
